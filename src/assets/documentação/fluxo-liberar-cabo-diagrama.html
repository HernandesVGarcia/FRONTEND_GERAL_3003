Fluxo de comunicação entre Google Maps, Serviços Angular e API Backend

📸 Como exportar como JPG:

  1. Aguarde o diagrama renderizar completamente abaixo
  2. Use a ferramenta de captura de tela do Windows (Win + Shift + S) ou Print Screen
  3. Selecione apenas a área do diagrama (sem as instruções)
  4. Salve a imagem como fluxo-liberar-cabo.jpg na pasta angular-google-maps/src/assets/
  5. Ou use a função de impressão do navegador (Ctrl + P) e salve como PDF/imagem
